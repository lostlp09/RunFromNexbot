# Guide
You are a killer or a survivor.As a survivor you need to stay alive for 5 minutes.You got Movment Abilitys like sliding and Sprinting.
As a Nextbot you job is it to kill all of the Survivors in 5 minutes.You can pick between three Character with unique Abilitys.
To unlock new Characters you need to play and Win.

# AntiCheat 
This game uses Roblox newest feature called Server Authority.Because of that there cant be any fly Hacks or speed hacks which is pretty good,but i needed to rewrite my animation and movment Code for this feature which i think took a lot time.

# Keybinds

W/S/A/D : Movment,
Ctr  Sprint,
C : Slid,
Ability Keybinds : Q/E
